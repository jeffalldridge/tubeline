# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep feedback about the work, and make this a
welcoming place for people of every background and experience level. Harassment of any
kind is not tolerated.

Report unacceptable behavior privately to the maintainer through GitHub
([@jeffalldridge](https://github.com/jeffalldridge)). Reports are handled confidentially, and
the maintainer may remove comments, commits or contributors that violate this code.
