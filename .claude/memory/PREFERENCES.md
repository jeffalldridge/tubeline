# Tubeline — Learned Preferences

## 2026-10-22
- Jeff thinks in motion-design terms: points, facets, strokes; wants minimal
  settings with good defaults and visible feedback (triangle count, preview).
- Prefers a solid flat color over shaded output.
- Position as a tool for motion graphics apps generally (Apple Motion is the flagship
  example, not the only target).
- Edge cases matter (caps, dashes, fills, intersections) — test them visually.
- Own test icons stay out of git (Samples/User); our generated samples are tracked.
