# Tubeline

All project instructions are in [AGENTS.md](AGENTS.md). Read it first, and don't duplicate its content here.

- **Starting a session:** read `.claude/memory/MEMORY.md`, then `AGENTS.md`.
- **The rule that can't be broken:** every icon becomes one closed solid. Never stitch separately meshed tubes together.
- **Build:** `cd app && xcodegen generate && xcodebuild -project Tubeline.xcodeproj -scheme Tubeline build`
- **Writing:** American English and the *Chicago Manual of Style*, in a natural voice. See the Writing section of AGENTS.md.
- **Git:** commit freely with Conventional Commits, but push only when Jeff asks.
