# Samples

Hand-made SVGs that exercise the converter's edge cases. They are original
artwork, safe to commit, and double as manual test fixtures.

| File | Covers |
| --- | --- |
| `plus-circle.svg`, `heart.svg`, `camera.svg` | Typical 24 pt line icons (round caps/joins, arcs, curves) |
| `edge-cases.svg` | Butt/round/square caps, dashes, dotted lines, a dashed circle, an outlined filled disc, a fill-only dot, crossing lines, transforms |
| `illustrator-style.svg` | Illustrator export with CSS classes and `px` units |
| `text-solid.svg` | Fill-only artwork (outlined text) with an even-odd hole |

Put your own icons in `User/` (gitignored).
