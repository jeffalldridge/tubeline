# Samples

These SVG files test how Tubeline handles common icons and edge cases. They're original artwork made for this project, so they're safe to share and modify.

| File | What it tests |
| --- | --- |
| `plus-circle.svg`, `heart.svg`, `camera.svg` | Typical 24 pt line icons with round caps and joins, curves, and a tiny dot |
| `edge-cases.svg` | Butt, round, and square caps; dashed and dotted lines; a dashed circle; a filled circle with an outline; a fill-only dot; crossing lines; transforms |
| `illustrator-style.svg` | An Illustrator export with CSS classes and `px` units |
| `text-solid.svg` | Fill-only artwork (outlined letters) with a hole that uses the even-odd fill rule |

Put your own test icons in the `User` folder, which Git ignores.
